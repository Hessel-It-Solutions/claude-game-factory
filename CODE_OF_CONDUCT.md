# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give and accept feedback on the work rather than the person, and keep harassment of any kind out of issues, pull requests and discussions.

To report a conduct problem, contact Hessel IT Solutions through https://hesselitsolutions.com. Reports are handled confidentially. Security issues follow [SECURITY.md](SECURITY.md).
